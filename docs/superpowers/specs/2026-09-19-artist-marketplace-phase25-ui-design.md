# Онлайн-галерея художников — Этап 2.5 (Интерфейс)

## Обзор

Этапы 1 и 2 реализованы и задеплоены, но интерфейс — сырой HTML без
стилей: в проекте нет Tailwind или UI-библиотеки, шрифт Arial, а
`globals.css` включает тёмную тему по `prefers-color-scheme`, из-за чего
прод открывается на почти чёрном фоне. Для галереи картин внешний вид —
значительная часть продукта, а Этап 3 (корзина, заказы) добавит ещё
много экранов. Поэтому оформление делается до него: экраны Этапа 3
сразу строятся из готовых деталей.

Этап 2.5 не добавляет функциональности. Меняется только оформление,
каркас страниц и языковая полировка (формы Clerk по-русски).

Решения, принятые с владельцем проекта:

- Стиль: минималистичный светлый, вариант **«Тёплый камень»**.
- Язык интерфейса: **только русский** (включая формы Clerk).
- Технологии: **Tailwind CSS v4 + shadcn/ui**.
- Главная: приветствие + свежие картины + призыв «Хочу продавать».

## Дизайн-основа

**Только светлая тема.** Из `app/globals.css` удаляется блок
`prefers-color-scheme: dark`; на `:root` задаётся `color-scheme: light`.

**Токены** (CSS-переменные на `:root`, подключены к Tailwind и shadcn):

| Токен | Значение | Назначение |
|---|---|---|
| фон | `#f6f2ec` | фон страниц |
| поверхность | `#fffdf9` | карточки, поля ввода |
| текст | `#2b2622` | основной текст |
| приглушённый текст | `#6f655a` | подписи, второстепенное (темнее исходного `#8a7f73`, чтобы на фоне `#f6f2ec` контраст был не ниже 4.5:1) |
| граница | `#d9cdbd` | линии, рамки полей и карточек |
| основной | `#2b2622` на `#f6f2ec` | основные кнопки, активный фильтр |
| акцент | `#b4562f` | цена, ссылки при наведении, кольцо фокуса |

Тень почти не используется, элементы отделяются границами. Скругления:
картины и карточки 6px, кнопки и поля 8px, фильтры-«пилюли» полностью.

**Шрифт.** Inter с кириллическим подмножеством через `next/font/google`
(самохостинг, без запроса к Google в рантайме). Заголовки: вес 600,
трекинг `-0.01em`.

**Каркас (`app/layout.tsx`).** Общая шапка и минимальный подвал для всех
страниц. Шапка: логотип «Галерея», ссылка «Каталог»; справа для
гостя «Войти» и «Регистрация», для вошедшего «Личный кабинет» и
`UserButton`. Контент в контейнере до 1200px, поля 16px на телефоне и
24px на десктопе. На узких экранах ссылки шапки уходят в выдвижное
меню (`Sheet` из shadcn).

**Адаптивность.** Мобильная версия — часть каждого экрана, а не
отдельный этап: покупатели, вероятно, заходят в основном с телефона.
Сетка карточек: 2 колонки на телефоне, 3–4 на десктопе.

**Clerk.** Подключается `ruRU` из `@clerk/localizations`. В `appearance`
передаются токены (цвета, шрифт, скругления), чтобы формы входа и
регистрации не выбивались из стиля. Страницы `sign-in`/`sign-up`:
форма по центру на общем фоне.

## Экраны

### Публичная часть

- **Главная (`/`).** Заголовок «Галерея художников», одно предложение о
  проекте, кнопки «В каталог» и «Хочу продавать картины» (ссылка: для
  гостя ведёт на `/sign-up`, для вошедшего на `/choose-role`; это
  ссылка, а не `button`, поэтому не пересекается с e2e-селектором
  `getByRole('button', { name: 'Хочу продавать картины' })` на
  `/choose-role`). Ниже сетка из
  6–8 последних опубликованных картин (переиспользует запрос каталога).
  Если картин нет — спокойная заглушка.
- **Каталог (`/gallery`).** Сверху панель фильтров (категория, техника,
  цена от/до, «Применить фильтры»). Ниже сетка карточек: фото 4:5,
  название, художник, цена акцентным цветом. Проданные картины в каталог
  не попадают (запрос отдаёт только `published`), поэтому плашка
  «Продано» показывается на странице картины и на странице художника.
  Пагинация «Назад / Вперёд» показывается, только если страниц больше
  одной. Цена везде в существующем формате `2200 TJS` (без разделителя
  тысяч: на нём завязан e2e).
  Пустой результат: «Ничего не найдено» и подсказка сбросить фильтры.
- **Страница картины (`/gallery/artwork/[id]`).** Десктоп: две колонки —
  слева крупное фото, справа название, художник (ссылка), цена,
  размеры, категория и техника, описание, кнопка «Написать художнику в
  Telegram». Телефон: одна колонка.
- **Страница художника (`/gallery/artist/[id]`).** Шапка: имя, «О себе»,
  Telegram-кнопка; ниже сетка его картин.

### Кабинеты

- **Художник (`/dashboard/seller`, `new`, `[artworkId]/edit`).** Список
  работ карточками со статусом-плашкой («На модерации», «Опубликовано»,
  «Отклонено», «Продано») и кнопками действий. Формы создания и
  редактирования: колонка около 640px, подписанные поля; при
  редактировании показано текущее фото (предпросмотр только что
  выбранного файла не делаем — нужен клиентский JS).
- **Админ (`/admin/sellers`, `artworks`, `categories`, `techniques`).**
  Очереди заявок и картин: карточка на элемент с кнопками «Одобрить» /
  «Отклонить». Категории и техники: строки с полем названия и кнопкой
  «Переименовать».
- **`/choose-role`, `/become-seller`, `/become-seller/status`,
  `/dashboard/buyer`.** Небольшая карточка по центру.

## Технические решения

- **Зависимости:** `tailwindcss` v4 (`@tailwindcss/postcss`), shadcn/ui
  (компоненты копируются в репозиторий, `components.json`), `clsx`,
  `tailwind-merge`, `class-variance-authority`, `lucide-react`,
  `@clerk/localizations`. Используемые из shadcn компоненты: Button,
  Badge, Input, Textarea, Sheet (без «на вырост»). Подписи полей —
  обычный `<label>` вокруг поля (как сейчас), меню пользователя — Clerk
  `UserButton`.
- **Формы и фильтры.** Фильтры каталога и формы на серверных действиях
  остаются на нативных `<select>`, `<input>`, `<textarea>` с классами
  Tailwind (не Radix-компоненты): они работают без JavaScript, и e2e
  не меняются.
- **Изображения.** `<img>` заменяется на `next/image` с `unoptimized`
  (обёртка `ArtworkImage`). Так не нужен список разрешённых хостов
  (e2e-фикстуры используют `https://example.com/*.png`), а Vercel Blob
  и так раздаётся через CDN. Это заодно закрывает 4 предупреждения
  линтера `@next/next/no-img-element`.
- **Общие компоненты** живут в `src/components/` (`ui/` — от shadcn,
  остальные — `ArtworkCard`, `ArtworkGrid`, `ArtworkImage`,
  `Pagination`, `SiteHeader`, `MobileNav`, `StatusBadge`, `Field`,
  `NativeSelect`, `AdminNav`). Контейнер страницы задаётся один раз в
  `app/layout.tsx`. Карточка картины и сетка используются
  на главной, в каталоге и на странице художника — один компонент,
  а не три копии.

## Тестирование

Существующие e2e ищут русские кнопки, заголовки, `section`, подписи
полей и `input[name="name"][value=…]`. Все эти элементы, тексты и
атрибуты сохраняются — меняется только оформление.

Единственное исключение — формы Clerk: их подписи меняются с английских
(`Continue`, `Email address`, `Password`, `Enter verification code`) на
русские. Эти подписи сейчас скопированы в 8 e2e-файлах. В рамках этапа
вход выносится в один общий хелпер `tests/e2e/helpers/clerk.ts`. Русские
строки в нём сверены с пакетом `@clerk/localizations` (`Почта`,
`Пароль`, `Продолжить`), а не вписаны по памяти; подпись поля кода в
пакете отсутствует, поэтому для неё используется регулярное выражение
на английский/русский вариант.

Проверка каждого шага: `npm run lint`, `npx tsc --noEmit`,
`npm run test:unit`, `npm run test:e2e` (11 тестов зелёные), плюс
ручной просмотр в браузере на ширине телефона и десктопа. Предупреждения
линтера `no-img-element` после этапа должны исчезнуть.

## Порядок работы

1. **Основа:** Tailwind, shadcn, токены, шрифт, `ruRU` Clerk, каркас
   (шапка/подвал), общий e2e-хелпер входа.
2. **Публичная часть:** главная, каталог, страница картины, страница
   художника, `next/image`.
3. **Кабинеты:** художник, админ, экраны выбора роли и заявки.

Каждый пункт — отдельный PR с зелёными e2e; между ними остальные экраны
остаются рабочими (просто ещё без нового оформления).

## Вне рамок Этапа 2.5

- Локализация на таджикский (только русский).
- Новая функциональность: поиск по тексту, страница со списком

- Анимации сверх простых состояний наведения и фокуса.
- Корзина, заказы, оплата (Этапы 3–4).
